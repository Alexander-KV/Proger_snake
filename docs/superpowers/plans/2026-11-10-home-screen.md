# План главного экрана

Цель: реализовать согласованное меню из docs/design.md на React и Tailwind.

- Подключить Tailwind через Vite и определить общие CSS-токены.
- Заменить стартовый шаблон двухколоночной композицией с SVG-визуализацией.
- Добавить пять кнопок меню и доступные с клавиатуры заглушки с возвратом.
- Реализовать заливку справа налево, белые маски, блюр и reduced-motion.
- Обновить AGENTS.md, README.md и описание текущего состояния.
- Выполнить ESLint, сборку и доступную проверку интерфейса в браузере.

Зависимости и структура остаются в рамках React/Vite. Игровой движок и сервер
не входят в эту задачу. Коммиты без запроса пользователя не создавать.
