# Архитектура Snake Arena

## Структура проекта

- `src/main.tsx`, `src/App.tsx` — точка входа и корневой компонент.
- `src/index.css` — подключение Tailwind CSS, токены темы и базовые стили.
- `src/App.css` — композиция главного экрана, визуализация и анимации.
- `src/App.tsx` — главное меню, SVG-иллюстрация и локальные заглушки разделов.
- `package.json`, `vite.config.ts`, `tsconfig*.json`, `eslint.config.js` — команды и настройки.
- `.codex/config.toml` — настройки Codex.
- `.codex/agents/reviewer.toml` — агент ревьюера.

## Учётные записи

`backend/main.py` содержит FastAPI API, проверку данных и Argon2id;
`backend/models.py` описывает таблицы SQLModel. Работа с SQLite выполняется
через SQLModel и SQLAlchemy. Данные команд и хеши случайных идентификаторов серверных сессий
хранятся в `data/snake-arena.db`. Сессия передаётся в HttpOnly SameSite-cookie,
живёт 7 дней и удаляется при выходе. Username сравнивается без учёта регистра,
уникальность обеспечивает ограничение БД. Запросы проверяют Origin; частота
попыток входа и регистрации ограничена в памяти процесса. Эта конфигурация
предназначена для локального запуска, а не многопроцессного развёртывания.

`src/AuthDialog.tsx` содержит формы и диалог для гостей; Vite проксирует `/api`
на FastAPI. Пользовательский код по-прежнему должен выполняться в отдельной
изолированной среде, не в процессе FastAPI.
