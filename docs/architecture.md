# Архитектура Snake Arena

## Структура проекта

- `src/main.tsx`, `src/App.tsx` — точка входа и корневой компонент.
- `src/index.css` — подключение Tailwind CSS, токены темы и базовые стили.
- `src/App.css` — композиция главного экрана, визуализация и анимации.
- `src/App.tsx` — главное меню, SVG-иллюстрация и локальные заглушки разделов.
- `package.json`, `vite.config.ts`, `tsconfig*.json`, `eslint.config.js` — команды и настройки.
- `.codex/config.toml` — настройки Codex.
- `.codex/agents/reviewer.toml` — агент ревьюера.
