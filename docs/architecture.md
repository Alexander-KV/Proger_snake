# Архитектура Snake Arena

## Структура проекта

- `src/main.tsx`, `src/App.tsx` — точка входа и корневой компонент.
- `src/index.css` — подключение Tailwind CSS, токены темы и базовые стили.
- `src/App.css` — композиция главного экрана, визуализация и анимации.
- `src/App.tsx` — главное меню, SVG-иллюстрация, авторизация и навигация.
- `src/matches/` — форма, список и лобби, клиент WebSocket.
- `backend/pyproject.toml`, `backend/uv.lock` — зависимости Python и lock-файл uv.
- `package.json`, `vite.config.ts`, `tsconfig*.json`, `eslint.config.js` — команды и настройки.
- `.codex/config.toml` — настройки Codex.
- `.codex/agents/reviewer.toml` — агент ревьюера.

## Учётные записи

`backend/main.py` содержит FastAPI API, проверку данных и Argon2id;
экспортирует `app` для запуска через `uvicorn backend.main:app`.
`backend/models.py` описывает таблицы SQLModel. Работа с SQLite выполняется
через SQLModel и SQLAlchemy. Данные команд и хеши случайных идентификаторов серверных сессий
хранятся в `data/snake-arena.db`. Сессия передаётся в HttpOnly SameSite-cookie,
живёт 7 дней и удаляется при выходе. Username сравнивается без учёта регистра,
уникальность обеспечивает ограничение БД. Запросы проверяют Origin; прокси Vite
сохраняет исходный Host, чтобы эта проверка работала при локальной разработке. Частота
попыток входа и регистрации ограничена в памяти процесса по IP клиента.
Vite перезаписывает `X-Snake-Client-IP` адресом входящего соединения; backend
принимает его только от loopback-прокси (`127.0.0.1`, `::1`) и проверяет формат IP.
При отсутствии или некорректном значении используется адрес соединения.
Uvicorn запускается с `--no-proxy-headers`, backend слушает `127.0.0.1`;
локальные процессы входят в границу доверия. Эта конфигурация
предназначена для локального запуска, а не многопроцессного развёртывания.

`src/AuthDialog.tsx` содержит формы и диалог для гостей; Vite проксирует `/api`
на FastAPI. Пользовательский код по-прежнему должен выполняться в отдельной
изолированной среде, не в процессе FastAPI.

## Матчи первого этапа

Маршрут `/api/ws` проксируется Vite в один процесс FastAPI. Допустимый Origin
соответствует адресу сайта. Сессия определяется по той же HttpOnly-cookie, что
и в HTTP API. При завершении или отзыве сессии её соединения закрываются.

`backend/matches.py` выполняет операции с таблицами матчей и текущего участия в
SQLite. Первичный ключ участия по ID команды обеспечивает ограничение одного
открытого матча. Транзакция с блокировкой записи защищает проверку вместимости
и занятие места. После записи `backend/match_socket.py` рассылает снимки
подписчикам, проверяя права доступа. При переподключении браузер заново
подписывается на свой экран и получает актуальный снимок.
