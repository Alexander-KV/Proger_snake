# Текущее состояние Snake Arena

## Назначение и реализация

Реализован светлый главный экран: анимированная декоративная арена слева
и меню справа — создание матча, матчи, редактор алгоритма, команды и правила.
Для вошедшей команды кнопки открывают заглушки разделов с возвратом в меню; гостям доступны правила, а остальные пункты предлагают регистрацию или вход. Реальные матчи и редактор кода пока недоступны. Визуализация не является игровым движком.
Используется Tailwind CSS через Vite; токены и правила — в [design.md](design.md).
Главный экран упрощён: убраны мелкие декоративные подписи и футер,
увеличена типографика меню; движение непрерывное, плавное и относительно быстрое.
Для reduced-motion декоративное движение и переходы отключены.
Реализованы FastAPI, SQLite с SQLModel, регистрация и вход с серверной сессией. Игровой движок и запуск алгоритмов пока не реализованы.
Точка входа `backend.main:app` экспортируется при импорте и проверяется backend-тестом.
Инфраструктура изолированного выполнения пользовательского кода пока не выбрана.

## Инструменты

Зависимости backend управляются через uv и `backend/pyproject.toml`, версии зафиксированы в `backend/uv.lock`. Для backend настроены тесты pytest; форматирование и его проверка настроены через Ruff. Для frontend используется Prettier.

## Требования

- [README.md](../README.md) — предварительное ТЗ, архитектура и открытые вопросы.

Нажатие на название в хедере возвращает в главное меню и прокручивает страницу
к началу, сохраняя хедер видимым.

## Регистрация и вход

Одна учётная запись соответствует одной команде. Регистрация принимает username,
отображаемое название из русских или английских букв, цифр, пробелов и `_` и пароль;
вход выполняется по username и паролю.
Данные и серверные сессии сохраняются в SQLite в `data/`. Для гостей доступны
главный экран и правила, остальные пункты показывают предложение войти.

Лимит входа и регистрации разделяется по IP клиентов Vite через доверенный
локальный прокси; подмена служебного заголовка внешним клиентом не учитывается.
